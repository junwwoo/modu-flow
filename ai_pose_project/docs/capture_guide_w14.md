# 자세 분석 데이터셋 촬영 가이드 (14주차)

운동 자세 분석기의 **검증·정확도 튜닝**에 쓸 영상을 촬영하는 가이드입니다.
영상을 보내주시면 담당자(박준우)가 프레임을 자동 추출해 데이터셋에 넣습니다.
**여러분은 촬영만** 하시면 됩니다. 도구 실행은 안 하셔도 됩니다.

---

## 0. 핵심 원칙 — "영상 1개 = 한 가지 동작"

가장 중요합니다. **한 영상에는 한 가지 라벨(정상 또는 특정 결함)만** 담아주세요.

- ✅ "상체 숙인 스쿼트"만 5~10회 한 영상에
- ❌ 정상 몇 번 + 숙인 거 몇 번 섞기 (❌ 섞으면 못 씁니다)

왜냐하면 "이 영상은 상체 숙임이다"라는 **정답(라벨)을 사람이 정해주는 방식**이기 때문입니다.
영상 단위로 동작을 정해 찍으면, 그 안에서 필요한 프레임은 도구가 알아서 골라냅니다.

---

## 1. 공통 촬영 설정

| 항목 | 권장 |
|---|---|
| 배경 | 단색 벽 등 깔끔하게. 다른 사람·사물 최소화 |
| 조명 | 밝게, 역광(창문 등지고) 금지 |
| 카메라 | 삼각대·거치대로 **고정** (흔들림 X) |
| 프레임 | **전신**이 다 들어오게. 특히 팔을 머리 위로 드는 운동은 **손끝까지** |
| 반복 | 한 동작을 **5~10회** 천천히. 정점(가장 깊게/높이)에서 **1초쯤 멈춤** |
| 방향 | 운동별 권장 각도(아래 표). 세로/가로 무관 — 전신만 들어오면 됨 |
| 길이 | 영상당 10~20초면 충분 |

> 세로로 찍은 폰 영상이 간혹 옆으로 눕는 경우가 있는데, 그건 담당자가 보정하니 신경 안 쓰셔도 됩니다.

---

## 2. 운동별 촬영 목록 (Shot List)

운동마다 **"정상" 영상 1개 + 각 "결함" 영상 1개씩**을 찍어주세요.
괄호 안은 라벨명(파일명에 사용).

### 하체 — **측면(side)**에서 촬영

| 운동 | 영상 | 어떻게 |
|---|---|---|
| **스쿼트** | 정상 (`good`) | 바른 자세로 5~10회 |
| | 무릎 넘김 (`knee_forward`) | 내려갈 때 무릎이 **발끝을 넘도록** |
| | 상체 숙임 (`trunk_lean`) | 내려갈 때 **상체를 앞으로 많이 숙이며** |
| | 좌우 비대칭 (`knee_asymmetry`) | **한쪽만 더 깊게** 내려가며 |
| **런지** | 정상 (`good`) | 바른 자세로 5~10회 |
| | 앞무릎 넘김 (`front_knee_forward`) | 앞다리 무릎이 **발끝을 많이 넘도록** |
| | 상체 숙임 (`trunk_lean`) | **상체를 앞으로 숙이며** |
| **푸시업** | 정상 (`good`) | 바른 자세로 5~10회 |
| | 엉덩이 처짐 (`hip_sag`) | 허리·엉덩이를 **아래로 축 처지게** |
| | 엉덩이 솟음 (`hip_pike`) | 엉덩이를 **위로 뾰족하게 들고** |

### 상체 — **정면(front)**에서 촬영 (카메라를 마주 보고)

| 운동 | 영상 | 어떻게 |
|---|---|---|
| **사레레** (사이드 레터럴 레이즈) | 정상 (`good`) | 양팔을 **어깨 높이까지** 옆으로, 좌우 같게 5~10회 |
| | 좌우 비대칭 (`asymmetry`) | **한쪽 팔만 더 높게** |
| | 과도 거상 (`arms_too_high`) | 팔을 **어깨보다 훨씬 위로** 번쩍 |
| **숄더프레스** | 정상 (`good`) | 양팔을 머리 위로 곧게, 좌우 같게 5~10회 |
| | 좌우 비대칭 (`asymmetry`) | **한쪽만 먼저/더 높게** 밀어 올리며 |
| **풀업** | 정상 (`good`) | 양팔로 고르게 5~10회 (가능한 만큼) |
| | 좌우 비대칭 (`asymmetry`) | **한쪽으로 치우쳐** 당기며 |

### 코어 — **측면(side)**에서 촬영

| 운동 | 영상 | 어떻게 |
|---|---|---|
| **싯업** | 정상 (`good`) | 바르게 일어났다 누웠다 5~10회 (결함 영상 없음) |

> **푸시업 정면(`camera_angle`)·런지 정면(`unknown_front_leg`)** 케이스는 담당자가 별도로 처리하니 위 목록만 신경 쓰시면 됩니다.

---

## 3. 파일명 규칙

영상 파일명을 아래처럼 지어주세요. 띄어쓰기 없이.

```
<멤버>_<운동>_<라벨>_<각도>.mp4
```

| 토큰 | 값 |
|---|---|
| 멤버 | `m1`(박준우) `m2`(이경민) `m3`(임용완) `m4`(정주영) |
| 운동 | `squat` `lunge` `pushup` `lateral_raise` `shoulder_press` `pullup` `situp` |
| 라벨 | 위 목록의 괄호 안 영문 (`good` `trunk_lean` `asymmetry` ...) |
| 각도 | `side` 또는 `front` |

**예시**
```
m2_squat_good_side.mp4
m2_squat_trunk_lean_side.mp4
m3_lateral_raise_asymmetry_front.mp4
m4_situp_good_side.mp4
```

> 파일명 짓기 헷갈리면, 영상마다 "누가 / 무슨 운동 / 어떤 동작 / 어느 방향"만 메모해서 같이 보내주셔도 됩니다.

---

## 4. 분량 — 많이 안 찍어도 됩니다

- **운동·라벨당 영상 1개**면 충분합니다 (그 안에서 대표 프레임 몇 장만 추출).
- 같은 동작을 한 사람이 수십 번 반복할 필요 **없습니다.**
- 대신 **4명이 각자** 찍어 주시면 체형 다양성이 생겨 가장 좋습니다.

목표: 운동·라벨당 4명 × 1개 영상.

---

## 5. 제출 전 체크리스트

- [ ] 한 영상에 **한 동작만** 담겼는가 (정상/결함 안 섞임)
- [ ] **전신**이 프레임에 들어오는가 (팔 든 운동은 손끝까지)
- [ ] 결함 영상은 그 결함이 **누가 봐도 명확**한가
- [ ] 권장 각도(하체·코어=측면 / 상체=정면)로 찍었는가
- [ ] 파일명 또는 메모로 **멤버·운동·라벨·각도**를 알 수 있는가
- [ ] 카메라가 고정돼 흔들리지 않는가

영상은 [공유 방법: 드라이브/메신저 등 팀 합의] 으로 보내주세요.
받으면 담당자가 추출 → 분석기 검증 → 정확도 튜닝까지 진행합니다.
